Companion extension for the Prism Rainmeter widget pack. Tracks your AI service usage and feeds it to desktop widgets, so you can see plan usage limits and API spend at a glance without opening a browser tab.

== What's new in 1.4 ==
- New Collect switch for each service in Settings: turn it off and the extension stops contacting that service entirely (no requests, no reading of its pages), and its desktop widget shows it as not connected. Every service is on by default. The Show switch next to it still only hides the row in the popup.
- Claude plan detection now reads your account's plan instead of always showing "Max".
- A brief network error or server hiccup no longer flips Claude, ChatGPT or Gemini usage to "Not connected": the last good reading is shown for up to 15 minutes instead.
- API spend that is not a live reading is now marked: Claude API spend shown after an error, OpenAI Platform spend taken on an earlier day, and Gemini API spend when a project could not be read.
- API spend: "Today" and "Yesterday" now use UTC days, and Yesterday is filled in on the 1st of the month.
- Google AI Studio: after reading the spend page, the extension puts your project, time range and model filter back, and it waits while you are using that tab. A project it could not read keeps its last value from this month instead of counting as $0.00.
- The extension's log no longer records the addresses of the pages you visit on platform.openai.com and aistudio.google.com.
- The privacy policy now also lists the widget pack's local log files, the settings your browser may sync, and each credential the extension uses.

== New in 1.3 ==
- ChatGPT usage tracking: live 5-hour session and weekly limit bars for your Codex usage, the same limits the ChatGPT app shows under "Usage remaining" (shown here as % used). Previously ChatGPT showed plan status only.
- ChatGPT plan detection now reads your active account, fixing paid plans that showed as Free.
- Cleaner popup: every service and setting now fits without scrolling.

== Supported services ==
- ChatGPT (chatgpt.com) - Codex 5-hour and weekly usage limits
- OpenAI Platform / API - month-to-date, today and yesterday spend
- Claude (claude.ai) - session and weekly usage limits
- Claude Console / API - month-to-date, today and yesterday spend
- Gemini (gemini.google.com) - session and weekly usage limits
- Google AI Studio - monthly spend, spend cap and tier

== How it works ==
The extension uses your existing browser sessions on each service. You stay logged in as normal; the extension reads the same usage data the website shows you and displays it in its popup. If the Prism widget pack is installed, it also hands the data to a small local helper that writes it to a file the Rainmeter widgets read. OpenAI Platform and Google AI Studio spend update while you have that site open in a tab. Any service you don't want tracked can be turned off with its Collect switch in Settings, and the extension then never contacts it.

== What you need ==
- A signed-in browser session on each service you want to track. That's all you need to see your usage in the extension popup.
- For the Rainmeter desktop widgets: the Prism Rainmeter widget pack and its native messaging host (one-click install via Setup.bat).

== What this extension does NOT do ==
- Never contacts a service whose Collect switch you turned off
- Your sign-ins are only ever sent to the service they belong to, never to the developer or any third party
- No data is sent to third-party servers
- No tracking, telemetry, or analytics
- Your usage data stays on your machine (if you use browser sync, your browser copies the extension's settings, such as the selected AI Studio project and which services are turned on, to your other signed-in browsers)
